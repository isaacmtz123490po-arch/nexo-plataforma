Una aplicación · PHP + Python

Python y PHP trabajan con el mismo Nexo

PHP sirve la interfaz y comunica las solicitudes del catálogo al servicio Python.

Una interfaz compartida

PHP entrega esta interfaz y recibe las solicitudes del catálogo. Después las envía al servicio privado de Python, que consulta SQLite y devuelve los resultados. Ambos forman parte de la misma aplicación.

01 · HTMLLa misma página adaptable.
02 · PHPEntrada web y conexión a Python.
03 · PythonProcesa y guarda el catálogo.

Qué funciona en esta demo

La búsqueda, los filtros, las fichas de apps y los guardados funcionan en el navegador. El inicio de sesión es de muestra y no verifica identidad. La integración PHP + Python procesa metadatos del catálogo; no ejecuta apps externas.

La sesión es simulada: no hay contraseña, cuenta real, autenticación ni sincronización entre dispositivos. El nombre se queda localmente en este navegador.
