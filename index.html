Dos backends, mismo catálogo

Python o PHP + HTML

El frontend sirve desde GitHub Pages; las APIs se ejecutan en un servidor con SQLite.

🐍 Opción Python

Flask entrega el catálogo JSON y guarda propuestas en SQLite.

pip install -r requirements.txt
python app.py

🐘 Opción PHP

Servidor integrado de PHP y PDO SQLite; reutiliza el mismo index.html.

php -S 127.0.0.1:8000 -t . router.php

El HTML publicado en Pages muestra el catálogo de ejemplo. Para cargar datos desde la API, ejecuta la app en un host compatible y sirve frontend y API desde el mismo origen.

Sobre ejecutar código de repositorios: esta plataforma no clona ni ejecuta automáticamente programas de terceros. Un repositorio público puede contener código peligroso. El catálogo solo muestra enlaces; para ejecutar apps ajenas hace falta revisión humana y un sandbox aislado, con límites de CPU/memoria/red, sin secretos ni acceso a datos del servidor.

Descubre primero. Ejecuta con cuidado.
